SYSTEM HANDBOOK

Documentation & Production Architecture

Comprehensive reference manual for prompt engineering, tokenization patterns, and runtime gateway protocols.

Multi-Gateway Protocol

NEXUS AI LAB interacts seamlessly with standard OpenAI-compatible completions endpoints (/chat/completions). You can switch between cloud providers or connect local servers like ollama run llama3 or vllm with zero client configuration changes.

Dual-Mode Execution (Live vs. Demo)

When an API key is connected, requests are dispatched with streaming SSE chunking to live models. When operating without credentials, the built-in deterministic simulator yields realistic model output, enabling full UI testing without external network dependencies.

Sampling Temperature vs. Nucleus Sampling

Do not modify both temperature and top_p simultaneously. In production prompt pipelines, lock Top P at 1.0 when varying Temperature for creative breadth, or lock Temperature at 0.2 and adjust Top P for grounded retrieval tasks.

Multi-Turn Threading

Use the + User Turn and + Assistant Turn controls to inject few-shot exemplars into context. The playground engine packages the entire ordered message array, accurately mimicking conversational state in chat-tuned checkpoints.

Resilience & Exponential Backoff

Network drops and HTTP 429 rate limits are automatically caught by client-side backoff retry loops. The playground retries failed chunks gracefully before falling back to comprehensive error reporting.

Zero-Trace Security Guarantee

All API keys and custom prompt histories are stored exclusively in client-side browser localStorage. Data is transmitted directly to provider endpoints over encrypted HTTPS with zero intermediary servers or telemetry logging.
